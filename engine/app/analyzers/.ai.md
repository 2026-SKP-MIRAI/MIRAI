# engine/app/analyzers/

## 목적
텍스트 기반 결정론적 신호 분석 모듈. LLM 미사용. 면접 답변에서 구조·품질·압박도 신호를 추출한다.

## 구조
```
analyzers/
├── __init__.py              공개 API (analyze, TextSignals, classify_pressure, calc_answer_quality, format_persona_signals)
├── text_analyzer.py         TextSignals 추출 — STAR, 모호도, 주도성, 구체성, 성취도 등
├── keywords.py              키워드 사전 및 임계값 상수
├── pressure_controller.py   압박도 분류 — calc_answer_quality + classify_pressure (CLARIFY/CHALLENGE/EXPLORE)
└── answer_signals.py        페르소나별 관심 신호 포맷팅 — format_persona_signals (hr/tech_lead/executive)
```

## 모듈별 역할

### text_analyzer.py
- `analyze(answer: str) -> TextSignals` 진입점
- TextSignals: has_content, star_score, vague_ratio, agency_verb_count, specificity_score, achievement_score, cause_analysis_count, alternative_count

### pressure_controller.py
- `calc_answer_quality(signals) -> float` — (star*0.5 + specificity*0.3 + achievement*0.2) * 100
- `classify_pressure(signals) -> FollowupType` — 우선순위: has_content=False→CLARIFY, vague>0.04→CLARIFY, agency==0→CLARIFY, quality<60→CHALLENGE, else→EXPLORE
- 임계값: ANSWER_QUALITY_CHALLENGE_THRESHOLD=60.0, VAGUE_RATIO_PRESSURE_THRESHOLD=0.04

### answer_signals.py
- `format_persona_signals(answer, signals, persona) -> str` — 페르소나(hr/tech_lead/executive)별 관심 신호 텍스트 반환
- 프롬프트 {persona_signals} 자리에 주입됨

## 불변식
- 모든 함수는 순수 함수 (side-effect 없음)
- LLM 호출 금지
- TextSignals는 text_analyzer에서만 생성
