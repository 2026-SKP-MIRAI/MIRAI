# engine/scripts/

## 목적

RAG 파이프라인 구축 및 데이터 적재용 스크립트 모음.

## 스크립트 목록

| 파일 | 역할 |
|------|------|
| `extract_pdf_resumes.py` | PDF 합격 자소서 → `accepted_resumes.json` 변환 |
| `build_resume_index.py` | `accepted_resumes.json` → Supabase 벡터 적재 |
| `analyze_accepted_resumes.py` | 적재된 데이터 분석 |

## 입력 데이터 규약 (`accepted_resumes.json`)

`build_resume_index.py`의 입력 파일 형식:

```json
[
  {
    "job_role": "연구개발",
    "content": "자기소개서 본문...",
    "source": "회사명"
  }
]
```

- `job_role`: PDF 파일명 `{id}_{company}_{job_role}.pdf`에서 자동 추출
- `content`: pypdf로 추출한 PDF 본문 텍스트
- `source`: 회사명 (PDF 파일명 2번째 파트)

## 데이터 생성 및 적재 절차

```bash
# 1. PDF → JSON 변환
python engine/scripts/extract_pdf_resumes.py \
  --input-dir "경로/to/pdfs" \
  --output accepted_resumes.json

# 2. JSON → Supabase 벡터 적재
python engine/scripts/build_resume_index.py \
  --input accepted_resumes.json
```

## 현황 (2026-03-27, #294)

## 주의사항

- 개인 식별 정보(이름·연락처) 포함 금지
- `accepted_resumes.json`은 7.20MB로 5MB 초과 → 레포에 커밋 금지
- `*.pdf`, `*.csv` 등 원본 파일은 커밋 금지 (`.gitignore` 적용)
