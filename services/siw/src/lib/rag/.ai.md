# RAG 라이브러리

## 역할
채용공고 벡터 검색 및 임베딩 관련 유틸리티.

## 파일 구조
- `embedding-client.ts` — 엔진 `/api/embed` 호출 클라이언트. `embedText(text)` 반환값: `{ vector: number[], model, tokenCount }` (`.vector` 사용). `ENABLE_RAG=false` 시 `null` 반환.
- `vector-search.ts` — Prisma `$queryRaw` + pgvector cosine similarity 검색. `searchSimilarPostings`, `extractTrendSkills`, `getTrendSkillsForRole` 함수 제공.

## 아키텍처 불변식
- 임베딩 생성(AI API 호출)은 반드시 엔진 경유 (embedding-client.ts → engine /api/embed)
- 벡터 DB 검색은 서비스가 직접 수행 (vector-search.ts → Prisma $queryRaw → pgvector)
- ENABLE_RAG=false 시 모든 RAG 코드 경로 비활성화
