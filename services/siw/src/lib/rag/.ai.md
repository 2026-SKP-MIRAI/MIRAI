# RAG 라이브러리

## 역할
채용공고 벡터 검색 및 임베딩 관련 유틸리티.

## 파일 구조
- `embedding-client.ts` — 엔진 `/api/embed` 호출 클라이언트. `embedText(text)` 반환값: `{ vector: number[], model, tokenCount }` (`.vector` 사용). `ENABLE_RAG=false` 시 `null` 반환. 공용 헬퍼 `getEngineBaseUrl()` (미설정 시 `null`) 및 `isValidEmbeddingVector()` (float 배열 검증) 함수 제공.
- `vector-search.ts` — Prisma `$queryRaw` + pgvector cosine similarity 검색. `searchSimilarPostings`, `extractTrendSkills`, `getTrendSkillsForRole` 함수 제공.
- `resume-search.ts` — `accepted_resume_embeddings` 테이블 대상 cosine similarity 검색. `searchSimilarAcceptedResumes(embedding, jobRole?, topK)` → `AcceptedResumeResult[]` 반환. `ENABLE_RESUME_RAG=true` 시 활성화.

## 아키텍처 불변식
- 임베딩 생성(AI API 호출)은 반드시 엔진 경유 (embedding-client.ts → engine /api/embed)
- 벡터 DB 검색은 서비스가 직접 수행 (vector-search.ts / resume-search.ts → Prisma $queryRaw → pgvector)
- ENABLE_RAG=false 시 채용공고 RAG 코드 경로 비활성화
- ENABLE_RESUME_RAG=false 시 합격 자소서 RAG 코드 경로 비활성화
- 두 RAG 모두 활성화돼도 임베딩은 1회만 호출 (성능 최적화)
- `$queryRaw` 삽입 전 반드시 `isValidEmbeddingVector()` 검증 — SQL injection 방지
- `ENGINE_BASE_URL` 미설정 시 localhost fallback 금지 — `getEngineBaseUrl()` 사용 (null 반환)
