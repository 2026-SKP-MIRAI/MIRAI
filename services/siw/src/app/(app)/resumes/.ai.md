# /resumes 페이지

## 목적
사용자의 이력서 목록 관리 페이지

## 기능
- 이력서 목록 조회 및 표시
- 이력서 카드: 내용 보기, 면접 시작, 삭제 버튼
- 이력서 카드 하단: 직무명(`inferredTargetRole`) 표시, 없으면 파일명 fallback
- 활성 뱃지: border-based transparent 스타일 (`border border-emerald-500`)
- 삭제 버튼: border-based transparent 스타일 (`border border-red-400`)
- 삭제: window.confirm 확인 → DELETE API 호출 → 목록에서 제거
- 이력서 추가 업로드 (UploadForm)

## 컴포넌트 구조
- `ResumesPage` (use client)
- 상태: resumes, loading, showUpload, deletingId
- API: GET /api/resumes (목록 — inferredTargetRole 포함), DELETE /api/resumes/[id] (삭제)

## 상세 페이지 (`[id]/page.tsx`)
- 자소서 분석 결과 (5축 점수, 강점/약점, 개선 제안)
- 8축 역량 평가 (면접 세션 평균)
- 성장 요약: 면접 회차별 점수 비교, `max-h-[280px]` 스크롤 적용
- 활성 뱃지("분석 완료"): border-based transparent 스타일
