# api/resume/questions — 이력서 질문 생성 엔드포인트

## 목적
업로드된 이력서 PDF를 파싱하고, 파싱된 텍스트 기반으로 면접 질문을 생성하는 API.

## 엔드포인트
`POST /api/resume/questions` — multipart/form-data (file: PDF)

## 처리 흐름
1. PDF 파일 검증 (File 인스턴스 여부, application/pdf MIME 타입)
2. 엔진 `/api/resume/parse` 호출 → `resumeText` 추출
3. 엔진 `/api/resume/questions` 호출 → 질문 목록 반환

## 타임아웃 체인
- `maxDuration`: 60s (Vercel 함수 최대 실행 시간)
- `AbortSignal.timeout`: 55000ms (parse·questions 각각)
- 엔진 LLM timeout: 50s
- 체인 보장: engine(50s) < fetch(55s) < maxDuration(60s)

## 에러 처리
- 파일 없음 / PDF 아님: 400
- 엔진 에러: 엔진 status 그대로 전파
- parse 실패: catch 후 에러 반환
- questions 실패: catch 후 llmError 반환
