# /api/resumes/[id]

## 목적
특정 이력서에 대한 API 엔드포인트

## 엔드포인트
- `GET /api/resumes/[id]` — 이력서 상세 조회 (인증 필요, 본인 이력서만)
- `DELETE /api/resumes/[id]` — 이력서 삭제 (인증 필요, 본인만 삭제 가능)

## DELETE 핸들러 흐름
1. 인증 확인 → 401 (미인증)
2. 이력서 존재 확인 → 404 (없음)
3. 소유권 확인 → 403 (타인 이력서)
4. Supabase Storage 파일 삭제 (실패 시 무시하고 계속)
5. DB 삭제 → 200

## 하위 라우트
- `download/` — 서명된 다운로드 URL 생성
- `feedback/` — AI 피드백 조회
- `sessions/` — 면접 세션 목록 조회
- `__tests__/` — GET/DELETE 엔드포인트 Vitest 테스트 (mock isolation: beforeEach에서 createServerClient mock 재설정 필수)

## 의존성
- `resumeRepository.findById`, `resumeRepository.deleteById`
- `createServerClient`, `createServiceClient` (Supabase)
