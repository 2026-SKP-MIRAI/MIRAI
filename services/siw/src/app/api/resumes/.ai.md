# services/siw/src/app/api/resumes/

## 목적
이력서 관련 API 엔드포인트 모음. PDF 업로드·분석·질문 생성·피드백 생성·저장까지 전체 흐름 처리.

## 구조
```
resumes/
├── route.ts              POST: PDF 업로드 + 질문 생성 + 피드백 생성 + DB 저장 (병렬)
│                         GET: 사용자 이력서 목록 조회
├── analyze/
│   └── route.ts          POST: PDF 파싱 + 직무 추출 (엔진 /api/resume/analyze 호출)
├── [id]/
│   ├── route.ts          GET/DELETE: 단일 이력서 조회·삭제
│   ├── feedback/
│   │   └── route.ts      POST: 이력서 피드백 재생성
│   ├── sessions/
│   │   └── route.ts      GET: 이력서 연결 면접 세션 목록
│   └── download/
│       └── route.ts      GET: PDF 원본 다운로드
└── trends/
    └── route.ts          GET: 직무별 트렌드 스킬 조회
```

## 타임아웃 체인
엔진 LLM 타임아웃(30s) < service fetch AbortSignal(55s) < ALB idle timeout(300s)

| 파일 | fetch 대상 | AbortSignal |
|------|-----------|-------------|
| `route.ts` | /api/resume/questions | 55000ms |
| `route.ts` | /api/resume/feedback | 55000ms |
| `analyze/route.ts` | /api/resume/analyze | 55000ms |

## 역할
- 인증은 이 레이어에서 처리 (Supabase auth)
- 엔진은 stateless — LLM 호출·파싱만 담당
- RAG(ENABLE_RAG, ENABLE_RESUME_RAG 환경변수)가 활성화된 경우 pgvector 검색 결과를 피드백 LLM에 주입
