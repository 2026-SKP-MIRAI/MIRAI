# /api/demo — 비인증 데모 API

## 목적
비로그인 사용자의 데모 면접 체험을 위한 엔진 프록시 API.
인증 불필요, IP 기반 rate limit (하루 3회) 적용.

## 엔드포인트
- POST /api/demo/question — 직무 기반 질문 생성 + rate limit (DemoUsage 테이블)
- POST /api/demo/feedback — 답변 피드백 (엔진 /api/practice/feedback 프록시)
- POST /api/demo/evaluate — 8축 평가 (엔진 /api/report/generate 프록시)

## Rate Limit
- 저장소: Prisma DemoUsage 테이블 (@@unique([ipHash, date]))
- IP 해싱: SHA-256(ip + DEMO_RATE_LIMIT_SALT)
- 기준: 하루 3회 (UTC 자정 리셋)
- question 라우트에서만 카운트 증가
