# /demo — 비로그인 데모 면접 체험 페이지

## 목적
가입 전 사용자에게 MirAI의 핵심 가치(AI 면접 피드백 + 8축 역량 분석)를 1문 체험으로 제공.
결과 저장 없음 — 아하 모먼트 경험 후 /signup으로 자연스럽게 전환.

## 구조
- `page.tsx` — 클라이언트 컴포넌트, 4단계 상태 머신 (select → answering → loading → result)

## 상태 머신
select → answering → loading → result
429 → 별도 에러 UI (rate limit 안내 + 가입 유도)

## 데모 모드 페르소나 및 평가 축
- 데모 모드는 `tech_lead` 페르소나를 고정으로 사용한다
- 결과 화면에 표시하는 평가 축은 **동적 상위 3축** — axisFeedbacks 중 score 상위 3개를 useMemo로 계산 (`topAxes`, page.tsx)
- 고정 축 없음: 답변 내용에 따라 표시 축이 달라짐
- 전체 8축 레이더 차트는 잠금 처리 → 가입 유도 CTA로 연결
- 출처: `engine/app/prompts/interview_followup_tech_lead_v3.md`

## 관련 API
- POST /api/demo/question — 질문 생성 (rate limit 포함)
- POST /api/demo/feedback — 답변 피드백
- POST /api/demo/evaluate — 8축 평가
