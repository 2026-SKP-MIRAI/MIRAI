# (auth) — 인증 페이지

## 목적
회원가입·로그인 등 인증 관련 페이지를 그룹화하는 라우트 그룹. 공통 레이아웃(배경, 로고)을 공유한다.

## 파일 구성
- `layout.tsx` — 인증 공통 레이아웃 (배경 orbs + 좌상단 MirAI 로고)
- `login/page.tsx` — 로그인 페이지
- `signup/page.tsx` — 회원가입 페이지 (use client)
  - Zod 스키마 기반 클라이언트 유효성 검사 (signupSchema)
  - Supabase `auth.signUp()` 호출
  - 중복 이메일 감지: `data.user?.identities` 빈 배열 여부로 판단 (Supabase 공식 패턴)
  - Google OAuth 가입 지원
- `terms/page.tsx` — 이용약관 페이지
- `privacy/page.tsx` — 개인정보처리방침 페이지
- `__tests__/layout.test.tsx` — 레이아웃 컴포넌트 테스트

## 레이아웃
- 좌상단 MirAI 로고: `gradient-text` 클래스, 클릭 시 랜딩페이지(`/`)로 이동
- 배경: `bg-[#F8F9FB] bg-grid` + 보라색 그라디언트 orb 2개
- children은 중앙 정렬 (`flex items-center justify-center`)

## 불변식
- 인증 로직은 서비스(Next.js)에서만 처리
- Supabase service role key는 서버 전용, 클라이언트 노출 금지

## 테스트
- `services/siw/tests/ui/signup.test.tsx` — 회원가입 폼 유효성 검사 + 중복 이메일 감지 테스트
- `services/siw/tests/ui/login.test.tsx` — 로그인 테스트
