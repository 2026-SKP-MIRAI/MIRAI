# (auth) — 인증 페이지

## 목적
회원가입·로그인 등 인증 관련 페이지를 그룹화하는 라우트 그룹. 공통 레이아웃(배경, 로고)을 공유한다.

## 파일 구성
- `layout.tsx` — 인증 공통 레이아웃 (배경 orbs + 좌상단 MirAI 로고)
- `login/page.tsx` — 로그인 페이지
- `signup/page.tsx` — 회원가입 페이지
- `terms/page.tsx` — 이용약관 페이지
- `privacy/page.tsx` — 개인정보처리방침 페이지
- `__tests__/layout.test.tsx` — 레이아웃 컴포넌트 테스트

## 레이아웃
- 좌상단 MirAI 로고: `gradient-text` 클래스, 클릭 시 랜딩페이지(`/`)로 이동
- 배경: `bg-[#F8F9FB] bg-grid` + 보라색 그라디언트 orb 2개
- children은 중앙 정렬 (`flex items-center justify-center`)
