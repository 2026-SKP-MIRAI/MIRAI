# airflow/ — LLM 품질 모니터링 배치

## 목적
S3에 적재된 LLM 이벤트 로그를 일별로 집계하여 analytics DB에 저장한다.

## 구조
- dags/llm_quality_dag.py: 일별 집계 DAG (extract → aggregate → load → alert)
- sql/001_create_llm_events_daily.sql: analytics DB DDL

## 구조 (추가)
- dags/job_crawl_dag.py: 워크넷 채용공고 크롤링 DAG — 매주 일요일 12:00 (crawl_list → crawl_details → embed_postings → upsert_vectors → log_summary)
- dags/worknet_client.py: 고용24(work24.go.kr) 주요기업 공채속보 크롤러
  - 목록: GET /wk/a/b/1700/themeEmpInfoSrchList.do (세션·CSRF 확보) →
          POST /wk/a/b/1700/themeEmpInfoSrchListPost.do (thmaHrplCd=S00074, resultCnt=100)
  - 상세: GET /wk/a/b/1500/empDetailAuthView.do (우대사항·직무내용 파싱)
  - 수집 대상: 주요기업 공채속보 테마 (코스피/코스닥 상장사·대기업 중심, 총 ~300건)
  - API 개인회원 제한·직종 필터 서버 세션 기반으로 HTML POST 크롤링 방식 채택
  - Rate limit: WORKNET_RATE_LIMIT_SEC Variable (기본 1.0초)
- sql/003_enable_pgvector.sql: pgvector extension + job_posting_embeddings DDL
- sql/004_accepted_resumes.sql: accepted_resume_embeddings 테이블 DDL (Issue #198 선행)
- sql/006_add_worknet_columns.sql: pref_cond(우대사항), job_cd(직종코드) 컬럼 추가
- tests/: pytest 단위 테스트 (conftest.py 포함, mock 기반 12개 케이스)
- requirements-dev.txt: 테스트 의존성 (-r requirements.txt + pytest + pytest-mock + moto[s3])

## DB 분리 구조
- 개인 Supabase (DATABASE_URL): 서비스 사용자 데이터 (Resume, InterviewSession)
- 공용 RAG Supabase (RAG_DATABASE_URL): 벡터 데이터 (job_posting_embeddings, accepted_resume_embeddings)
- job_crawl_dag는 RAG_POSTGRES_CONN_ID로 공용 RAG Supabase에 직접 write

## 배치 파이프라인 DB 접근 원칙
Airflow job_crawl_dag는 공용 RAG Supabase(job_posting_embeddings)에 직접 write. 개인 Supabase(DATABASE_URL)와 분리된 별도 인스턴스.

## 실행 조건 (Phase B)
1. EC2 배포 완료 + S3 버킷 mirai-logs 생성
2. Airflow Variable 설정: S3_LOG_BUCKET, S3_LOG_PREFIX, ANALYTICS_DB_CONN
3. Airflow Connection 설정: analytics_db (PostgreSQL)

## 실행 조건 (job_crawl_dag — 워크넷 크롤링)
1. Airflow Variable 설정:
   - `S3_RAG_BUCKET_NAME`: S3 버킷명
   - `ENGINE_BASE_URL`: 엔진 서버 URL (임베딩 API 호출)
   - `RAG_POSTGRES_CONN_ID`: RAG DB 연결 문자열
   - `WORKNET_RATE_LIMIT_SEC`: 크롤링 요청 간격 (기본 1.0초, 선택)
2. pgvector extension 활성화 (sql/003_enable_pgvector.sql)
3. job_posting_embeddings 테이블에 워크넷 컬럼 추가 (sql/006_add_worknet_columns.sql)
4. requirements-dev.txt로 로컬 테스트 (moto[s3] 포함), prod은 requirements.txt만 사용

> ⚠️ work24.go.kr 채용정보 Open API는 개인회원 이용 불가. HTML 크롤링으로 대체.
> 이용약관 준수: 비상업적 교육 목적, 과도한 요청 금지 (rate_limit_sec ≥ 1.0 권장)
