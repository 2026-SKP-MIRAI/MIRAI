# services/siw/tests/

## 목적
siw 서비스의 통합 테스트 모음. API 라우트·UI 컴포넌트·E2E 시나리오를 분리된 디렉토리에서 관리한다.

## 구조
```
tests/
├── setup.ts          전역 Vitest 셋업 — ENGINE_BASE_URL 등 env 사전 설정
├── api/              API 라우트 통합 테스트 (13개 파일)
├── ui/               UI 컴포넌트 렌더링 테스트 (17개 파일)
├── unit/             순수 유닛 테스트
└── e2e/              E2E 시나리오
```

## setup.ts 역할
- `process.env.ENGINE_BASE_URL = "http://localhost:3001"` — 모든 테스트 파일보다 먼저 실행되어 라우트 핸들러가 `getEngineBaseUrl()` 호출 시 `undefined` URL로 500 반환하는 것을 방지
- `vi.stubEnv` 대신 `process.env` 직접 할당 — `vi.unstubAllEnvs()` 호출에 영향을 받지 않음 (의도적 설계)

## 불변식
- `vi.stubEnv`로 설정한 환경변수는 `vi.unstubAllEnvs()` 호출 시 제거됨 → ENGINE_BASE_URL처럼 항상 필요한 값은 `process.env` 직접 할당
- 각 테스트 파일은 `beforeEach`에서 `vi.clearAllMocks()` + `vi.resetModules()` 호출로 mock 오염 방지
