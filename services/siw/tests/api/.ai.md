# services/siw/tests/api/

## 목적
siw API 라우트 핸들러 통합 테스트. 실제 라우트를 동적 import(`await import(...)`)로 불러와 Request 객체를 직접 전달하여 동작을 검증한다.

## 테스트 파일 목록
| 파일 | 대상 라우트 |
|------|-------------|
| `resumes-route.test.ts` | POST/GET `/api/resumes` |
| `resumes-analyze-route.test.ts` | POST `/api/resumes/analyze` |
| `resume-feedback-route.test.ts` | POST `/api/resumes/[id]/feedback` |
| `resume-questions-route.test.ts` | GET `/api/resumes/[id]/questions` |
| `growth-sessions-route.test.ts` | GET `/api/growth/sessions` |
| `interview-start-route.test.ts` | POST `/api/interview/start` |
| `interview-answer-route.test.ts` | POST `/api/interview/answer` |
| `interview-complete-route.test.ts` | POST `/api/interview/complete` |
| `practice-feedback-route.test.ts` | POST `/api/practice/feedback` |
| `report-generate-route.test.ts` | POST `/api/report/generate` |
| `observability-route.test.ts` | GET `/api/observability` |
| `trends-route.test.ts` | GET `/api/resumes/trends` |
| `error-messages.test.ts` | 에러 메시지 상수 검증 |

## 패턴
- `vi.doMock` + `vi.resetModules()` — 테스트별 모듈 재로드로 mock 격리
- `process.env.ENGINE_BASE_URL` — `tests/setup.ts`에서 전역 설정, 개별 파일에서 재설정 불필요
- `growth-sessions-route.test.ts` mock 구조: `resume: { fileName, inferredTargetRole }` 중첩 객체 (flat `resumeText` 아님)
