# services/siw/tests/ui/

## 목적
siw UI 컴포넌트 렌더링 테스트. `@testing-library/react`로 컴포넌트를 렌더링하고 화면 텍스트·속성·구조를 검증한다.

## 테스트 파일 목록
| 파일 | 대상 컴포넌트 |
|------|--------------|
| `landing-page.test.tsx` | `app/(landing)/page.tsx` — 랜딩 페이지 섹션 렌더링 |
| `upload-form.test.tsx` | 이력서 업로드 폼 |
| `growth-page.test.tsx` | 성장 페이지 (`resumeFileName` 필드 사용) |
| `dashboard-page.test.tsx` | 대시보드 페이지 |
| `interview-*.test.tsx` | 면접 관련 컴포넌트 |
| `report-result.test.tsx` | 리포트 결과 페이지 |

## 주의사항
- 컴포넌트 텍스트 변경 시 이 디렉토리 assertion도 함께 동기화 필요
- `upload-form.test.tsx`: 직무 입력 placeholder는 `"직무 미지정"`, 직무 확인 배지는 `"지원 직무 확인"`
- `growth-page.test.tsx`: mock data 필드명은 `resumeFileName` (구 `resumeLabel` 아님)
- `landing-page.test.tsx`: 다중 매칭 텍스트는 `getAllByText(...)[0]` 패턴 사용
