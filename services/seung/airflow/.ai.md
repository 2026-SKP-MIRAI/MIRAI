# airflow — seung 데이터 파이프라인

## 목적
seung 서비스의 데이터 파이프라인 모음.
- 면접 세션 일별 집계 → S3 적재
- 사용자 제출 합격 자소서 임베딩 → RAG DB 적재

## 구조
- `dags/seung_analytics_dag.py` — 면접 세션 일배치 DAG (extract → compute → load → alert)
- `dags/seung_resume_embed_dag.py` — 합격 자소서 임베딩 DAG (find → embed → upsert → mark)
- `tests/` — pytest 단위 테스트
- `docker-compose.yml` — Airflow standalone (webserver + scheduler)

## 실행
EC2에서: `docker compose up -d`
Airflow UI: http://{EC2_IP}:8080

## 기술부채

### alert_on_low_completion — 현재 로그 전용
현재 completion_rate < 30% 시 `logger.warning()`만 호출. Slack/email 등 실제 알림 채널 미연동.
- **현재 수용 조건**: 학습 프로젝트 — 로그 모니터링으로 대체
- **전환 트리거**: 운영 모니터링 필요 시 Slack Webhook 연동

### SQLite 메타DB (Airflow standalone)
현재 `command: standalone`은 SQLite 기반 단일 프로세스 모드로, Airflow 공식 문서에서 개발/테스트 전용으로 분류한다.
- **위험**: 동시 쓰기 충돌(`database is locked`) 가능성
- **현재 수용 조건**: 학습 프로젝트 — 팀이 위험을 인지하고 운영
- **전환 트리거 조건 충족됨**: #293(`seung_resume_embed_dag`)으로 두 번째 DAG 추가됨. PostgreSQL 메타DB 전환 검토 필요.
  현재는 두 DAG 스케줄이 겹치지 않아(analytics 15:00 UTC, embed 16:00 UTC) 즉시 전환 불필요로 판단. 운영 확장 시 전환.

## 아키텍처 불변식 4 예외 사항
이 DAG는 seung Postgres DB에 psycopg2로 직접 접근한다.
이는 아키텍처 불변식 4("DB는 서비스가 소유")의 **의도적 예외**다.
- 이유: Python 배치 파이프라인에서 Prisma ORM 사용 불가
- 완화 조건 (읽기): `seung_db_readonly` 읽기 전용 역할(SELECT 전용) 사용
- 완화 조건 (쓰기): `seung_resume_embed_dag`의 `mark_processed`는 `SEUNG_DATABASE_URL`로 쓰기 접근. 처리 대상 ID만 UPDATE하는 최소 권한 원칙 준수.
- 기술부채 트리거 조건 충족됨: #293으로 두 번째 DAG가 app DB 쓰기 접근. 내부 export API 분리는 운영 트래픽 증가 시 검토. 현재는 학습 프로젝트 규모로 수용.

## AWS 자격증명 방식
EC2 IAM Instance Role 사용 — boto3가 자동으로 Role 자격증명을 주입.
`AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY`를 코드나 환경변수에 명시하지 않는다.

IAM Role에 필요한 최소 권한:
- `s3:GetObject` — Raw Zone 읽기 (compute_metrics)
- `s3:PutObject` — Raw/Processed Zone 쓰기 (extract_sessions, load_to_s3)
- 리소스: `arn:aws:s3:::mirai-seung-analytics/*`

## 필요 Airflow Variables / Connections

### seung_analytics_dag
- Variable `SEUNG_S3_ANALYTICS_BUCKET` — S3 버킷명
- Connection `seung_db_readonly` — seung DB 읽기 전용

### seung_resume_embed_dag
- Variable `RAG_DATABASE_URL` — pgvector Supabase 연결 문자열 (미설정 시 DAG graceful skip)
- Variable `SEUNG_DATABASE_URL` — seung DB 쓰기 연결 문자열 (mark_processed 전용)
- Variable `ENGINE_BASE_URL` — 엔진 URL (기본값: http://localhost:8000)
- Connection `seung_db_readonly` — seung DB 읽기 전용 (analytics DAG와 공유)

### 공통
- `AIRFLOW_SECRET_KEY` — Airflow webserver secret key (환경변수)
