# RAG 라이브러리

## 역할
합격 자소서 벡터 검색 및 임베딩 관련 유틸리티.
면접 질문 생성·서류 진단 시 합격 자소서 유사 사례를 `resume_context`로 엔진에 주입한다.

## 파일 구조
- `embedding-client.ts` — 엔진 `/api/embed` 호출 클라이언트. `embedText(text)` 반환값: `{ vector: number[], model, tokenCount }`. `ENABLE_RAG=false` 시 `null` 반환.
- `resume-search.ts` — `ragPrisma.$queryRaw` + pgvector cosine similarity 검색. `searchSimilarAcceptedResumes(embedding, jobRole?, topK)` → `AcceptedResumeResult[]` 반환.
- `rag-prisma.ts` — RAG DB 전용 Prisma 클라이언트 (`RAG_DATABASE_URL` 환경변수). `accepted_resume_embeddings` 테이블 접근용.

## 아키텍처 불변식
- 임베딩 생성(AI API 호출)은 반드시 엔진 경유 (`embedding-client.ts` → engine `/api/embed`)
- 벡터 DB 검색은 서비스가 직접 수행 (`resume-search.ts` → `ragPrisma.$queryRaw` → pgvector)
- `ENABLE_RAG=false` 시 전체 RAG 코드 경로 비활성화 — 기존 동작 완전 유지
- RAG 실패(임베딩 오류·검색 오류) 시 graceful degradation — 에러 전파 금지

## 환경변수
- `ENABLE_RAG` — `true` 시 RAG 활성화 (기본 `false`)
- `RAG_DATABASE_URL` — pgvector DB 접속 URL (공용 Supabase, `accepted_resume_embeddings` 테이블 포함)
- `ENGINE_BASE_URL` — 엔진 기본 URL (`embedding-client.ts`에서 사용)

## 사용처
- `src/app/api/resume/feedback/route.ts` — DB 조회 후 RAG 파이프라인 실행, `callEngineFeedback`에 `resume_context` 주입
