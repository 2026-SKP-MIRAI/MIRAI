# src/components/

## 목적

공유 UI 컴포넌트. 여러 페이지에서 재사용되는 컴포넌트를 여기에 둔다.

## 파일 목록

| 파일 | 역할 |
|------|------|
| `NavBar.tsx` | 공통 상단 내비게이션 (`/login`·`/signup`에서 숨김, sticky, 로그아웃 버튼) |
| `UploadForm.tsx` | PDF 업로드 폼 — idle/uploading/processing/done/error 5가지 상태 |
| `QuestionList.tsx` | 카테고리별 예상 질문 리스트 + 다시하기 버튼 |
| `InterviewChat.tsx` | 면접 채팅 UI — 페르소나별 색상, 꼬리질문 배지, 리포트 생성 버튼, 연습 모드 피드백 블록 |
| `AnswerInput.tsx` | 답변 입력 textarea — 5000자 제한, beforeunload 이탈 경고 (내용 있을 때만) |
| `Spinner.tsx` | 로딩 스피너 SVG — `className` prop (기본값: `h-8 w-8 text-[#4361ee]`) |
| `ScoreGauge.tsx` | 원형 점수 게이지 SVG — `score` prop (0–100), 점수 구간별 색상 자동 결정 |
| `RadarChart.tsx` | recharts 기반 레이더 차트 — `data: { axis, label, score }[]` prop, `'use client'` 필수 (recharts DOM 의존) |

## 규칙

- 페이지 전용 컴포넌트는 여기에 두지 않는다 (해당 페이지 디렉토리에 둔다).
- `Spinner`와 `ScoreGauge`는 서버·클라이언트 컴포넌트 양쪽에서 사용 가능한 순수 렌더링 컴포넌트다 (`'use client'` 없음).
- `RadarChart`는 recharts DOM API 의존으로 `'use client'` 필수 — 클라이언트 컴포넌트 페이지에서만 import할 것.
