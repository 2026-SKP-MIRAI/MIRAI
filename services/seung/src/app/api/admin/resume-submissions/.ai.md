# api/admin/resume-submissions/

## 목적
합격 자소서 제출 관리 API. 어뷰징 탐지 및 허위 제출 삭제용.
`ADMIN_EMAIL` 환경변수와 로그인 이메일이 일치하는 경우만 접근 가능.

## 엔드포인트
- `GET ?processed=true|false&page=N` — 제출 목록 반환 (최신순, take:50). 파라미터 생략 시 전체/1페이지 반환. content 컬럼 제외 (목록용)
- `DELETE ?id={id}` — 특정 제출 삭제. 존재하지 않는 id → 404 (Prisma P2025)

## 인증
`ADMIN_EMAIL` 환경변수 설정 필수. Supabase 로그인 이메일과 **대소문자 무관** 비교.
미일치 시 403, 미로그인 시 401, 환경변수 미설정 시 503.
