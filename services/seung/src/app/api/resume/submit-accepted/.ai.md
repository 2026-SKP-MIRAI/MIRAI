# api/resume/submit-accepted/

## 목적
합격 자소서 제출 API. 로그인 사용자가 기여한 자소서를 `ResumeSubmission` 테이블에 저장.
저장된 데이터는 #293 임베딩 파이프라인 DAG가 주기적으로 읽어 처리한다.

## 엔드포인트
- `GET` — 인증 불필요. 전체 제출 건수 반환 `{ count: N }`
- `POST` — 로그인 필수. FormData(`file` PDF, `jobRole`, `company?`, `consent`) 수신 → 엔진 PDF 텍스트 추출(`callEngineAnalyze`) → 유효성 검증 → DB 저장 → `{ id, createdAt }` 반환

## 유효성 검증
- `jobRole`: 필수 (자유 입력)
- `file`: PDF 필수, 5MB 이하
- 추출된 텍스트: 200자 이상 필수
- `consent`: 'true' 필수
- Rate limit: 유저당 10건/24h
