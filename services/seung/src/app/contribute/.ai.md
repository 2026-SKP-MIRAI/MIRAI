# app/contribute/

## 목적
로그인 사용자가 합격 자소서를 자발적으로 제출하는 기여 페이지.
제출된 데이터는 서류 진단 RAG 품질 향상에 사용된다.

## 구조
```
contribute/
└── page.tsx   ← 'use client' — 기여 폼 (직군 자유 입력, 회사명, PDF 업로드, 동의 체크박스)
```

## 역할
- `GET /api/resume/submit-accepted` 로 전체 기여 건수 표시
- `POST /api/resume/submit-accepted` 로 제출
- 제출 완료 후 임팩트 메시지 표시
- 미로그인 접근 시 middleware가 `/login?redirectTo=/contribute` 로 리디렉트
