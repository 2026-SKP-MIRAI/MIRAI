# app/admin/

## 목적
관리자 전용 페이지. `ADMIN_EMAIL` 환경변수에 등록된 이메일 사용자만 접근 가능.
미로그인 또는 비관리자 접근 시 middleware가 `/login?redirectTo=/admin/...`으로 리디렉트.

## 구조
```
admin/
└── submissions/
    └── page.tsx   ← 'use client' — 합격 자소서 제출 목록 조회 + 삭제
```

## 역할
- `GET /api/admin/resume-submissions` — 전체 제출 목록 조회 (최신순, processed 필터, page 파라미터)
- `DELETE /api/admin/resume-submissions?id={id}` — 허위/어뷰징 제출 삭제
- 관리자 인증은 API 레벨에서 처리 (`ADMIN_EMAIL` 비교)
