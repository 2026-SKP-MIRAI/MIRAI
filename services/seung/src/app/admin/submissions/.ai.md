# app/admin/submissions/

## 목적
합격 자소서 제출 내역 관리 페이지. 어뷰징 탐지 및 허위 제출 삭제용.

## 구조
```
admin/submissions/
└── page.tsx   ← 'use client' — 제출 목록 조회 + 삭제 버튼
```

## 역할
- `GET /api/admin/resume-submissions` 로 전체/필터 목록 조회
- `DELETE /api/admin/resume-submissions?id={id}` 로 삭제
- 관리자 인증은 API 레벨에서 처리 (`ADMIN_EMAIL` 환경변수)
- 미로그인/비관리자 접근 시 API가 401/403 반환
