## 2026년 3월 30일 주차 (Mar 30~Apr 5)

### ✨ 새 기능
- **자소서 업로드 → Supabase Storage 저장 + 면접 맞춤 질문 연동** ([#180](../../issues/180)): 자소서 PDF를 Supabase Storage에 업로드하고, 해당 내용 기반으로 맞춤 면접 질문이 생성됩니다.
- **Phase 1 크레딧 시스템 기초** ([#181](../../issues/181)): 면접 완료 시 코인이 지급되고 잔액 UI가 추가되었습니다.
- **리포트 카드 SNS 공유** ([#184](../../issues/184)): OG 이미지 자동 생성 + 카카오톡 공유 버튼이 추가되었습니다.

### 🛡️ 보안 / 품질
- **middleware rate limiter Upstash Redis 교체** ([#183](../../issues/183)): in-memory Map 기반 rate limiter를 Upstash Redis로 교체하여 서버리스 환경에서도 정확한 요청 제한이 적용됩니다.
