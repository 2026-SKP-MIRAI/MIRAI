# Fint 핵심 화면 스토리보드

> 최종 업데이트: 2026-03-23 (이슈 #194 서비스명 Fint 통일 + IA 5탭 구조 반영)
> 모바일 기준 375px. ASCII 목업은 실제 레이아웃 가이드용.
> 브랜드 컬러: Primary #0D9488 (Teal, 옵션 B 확정) | 서비스명: Fint

## 작성 규칙

- ASCII 박스 너비: 21자 단일 표준 `┌─────────────────────┐`
- 크레딧 수치는 CONFIG 상수 사용:
  - 면접 완료 보상: +CREDIT_INTERVIEW_COMPLETE (기본값: 5)
  - 후기 작성 보상: +CREDIT_REVIEW_WRITE (기본값: 5)
  - 스트릭 7일 보너스: +CREDIT_STREAK_BONUS_7 (기본값: 10)
  - 페르소나 면접 비용: -CREDIT_PERSONA_INTERVIEW (기본값: 10)
  - 쪽지 발송 비용: -CREDIT_DM_SEND (기본값: 3)
  - Q&A 패턴 열람 비용: -CREDIT_PATTERN (기본값: 3)
  - 스트릭 복구 비용: -CREDIT_STREAK_RECOVER (기본값: 5)
  - 응원 폭탄 발송 비용: -CREDIT_CHEER_SEND (기본값: 2)
  - 연봉 통계 상세 열람 비용: -CREDIT_ANALYTICS_VIEW (기본값: 5)
  - 현직자 크레딧 배분율: CREDIT_PERSONA_CREATOR_SHARE (기본값: 3, CREDIT_PERSONA_INTERVIEW의 30%)
  - 실제 수치는 `services/fint/src/config/credits.ts`에서 관리
- 상태별 목업: 각 화면에 최소 Happy Path + 빈/에러 상태 1개 이상
- 타임존: 스트릭 자정 기준 = 한국 시간(UTC+9)
- 소셜 로그인: 모바일 웹 = 리다이렉트 방식
- color-warning: Error Red #EF4444 (크레딧 부족 경고, Amber가 아님)
- color-coin: Amber #F59E0B (크레딧 표시 전용)

⚠ 접근성 주의: color-coin (#F59E0B)는 흰 배경(#FFFFFF) 위에서 WCAG AA 대비(4.5:1) 미충족 (실제 약 2.4:1). 사용 규칙: 아이콘·뱃지 배경으로만 사용, 흰 배경 위 본문 텍스트 색상으로 직접 사용 금지. 텍스트가 필요한 경우 color-coin 배경 위에 어두운 텍스트(#000) 또는 color-coin을 배경으로 사용.

## 화면 1 [MVP]: 온보딩 — 스플래시 + 소개 슬라이드

### 시나리오

이취준이 앱스토어에서 Fint를 설치하고 처음 실행한다. 스플래시 화면이 1.5초간 표시된 후 3장의 소개 슬라이드가 나타난다. 슬라이드를 넘기면서 "면접 연습을 채팅으로 한다", "즉각적인 결과 리포트를 받는다"는 핵심 가치를 이해한다. 마지막 슬라이드에서 "바로 시작하기" 버튼을 눌러 로그인 없이 직군 선택으로 진입한다. **MVP에서는 로그인 없음 — 선 체험 후 가입. 크레딧·현직자 연결 기능 없음.**

### 목적

- 앱의 핵심 가치 3가지를 30초 안에 전달
- 로그인 없이 즉시 진입 — 마찰 제로, Aha Moment까지 최단 경로

### 핵심 요소

- 앱 로고 (Teal #0D9488)
- 슬라이드 인디케이터 (● ○ ○)
- "바로 시작하기" CTA 버튼 (로그인 없음)
- 스킵 버튼 (우상단)

## 화면 1-2 [MVP]: 온보딩 — 프로필 설정 (취준생)

### 시나리오

로그인 없이 바로 진입한 이취준. "1단계만 하면 첫 면접을 시작할 수 있어요" 안내와 함께 직군 선택 + 취준 단계 선택이 1화면에서 통합 처리된다. 자소서 업로드는 Phase 1부터 제공. 완료 후 즉시 첫 면접 CTA가 표시된다.

### 목적

- AI 맞춤 질문 생성의 개인화 기반 마련
- 핵심 입력 1단계 원칙 준수: 직군 + 취준 단계를 1화면에서 동시 입력 → 즉시 면접 시작
- 마찰 최소화 — 로그인 없이 즉시 체험 진입

### 핵심 요소

- 직군 + 취준 단계 **1화면 통합** (스크롤 1페이지)
- 직군 선택 (최대 3개, 인기 직군 상단 고정)
- 취준 단계 선택 (서류 준비 / 면접 준비 / 최종합격 대기)
- 자소서 업로드 (선택, 스킵 버튼 제공, 업로드 시 혜택 강조)
- 첫 면접 시작 CTA

## 화면 2 [Phase 2+]: 홈 피드

### 시나리오

로그인 직후 첫 화면. 취준생·현직자·AI 페르소나의 게시물이 뒤섞여 있다. AI 게시물에는 🤖 배지가 자동 표시되어 누구나 한눈에 확인할 수 있다. 상단에는 크레딧 잔액과 오늘의 스트릭이 노출된다. **이 화면은 Phase 2+3 기능 (개발 레퍼런스용) — MVP에서는 홈 피드 없음.**

### 목적

- 커뮤니티 활성감 제공 (AI + 실사용자 혼재)
- 크레딧 소비 동기 부여 (아차포인트 열람, 면접 운세)
- 면접 시작 CTA 자연스럽게 노출

### 핵심 요소

- 상단 바: 로고, 크레딧 잔액, 알림 아이콘
- 스트릭 위젯 (7일 캘린더)
- 피드 카드: 익명 프로필, 게시글 요약, 좋아요/댓글 수
- 🤖 AI 배지 자동 표시 (크레딧 불필요, 디폴트 오픈)
- 오늘의 면접 운세 배너 (크레딧 소비)

- "취소" 텍스트 링크
- 드래그 다운 또는 배경 탭 → '취소' 동작과 동일 (`returnTo` 화면 복귀). 시트 외부: 반투명 딤(rgba 0,0,0,0.5) 적용.

5. 실패: 에러 코드별 모달 → 재시도/취소

> PG 연동 상세: `docs/specs/fint/payment_spec.md` 참조

### 이탈 params

- 패키지 선택: 3종 카드

- 성공: 크레딧 충전 완료 + returnTo 복귀

## 화면 31 [Phase 2+]: 연봉 통계/이직 타이밍 분석

> 현직자 전용 화면. **최현직 페르소나** 시나리오.

### 시나리오

최현직이 프로필 탭에서 "연봉 통계" 메뉴를 탭한다. 자신의 직군(개발) 연봉 분포와 이직 적정 시기를 확인한다.

### 목적

현직자 전용 프리미엄 콘텐츠로 리텐션 강화

### 핵심 요소

- 직군별 연봉 분포: 범위 바 차트 (min-median-max, horizontal). 데이터 포인트: 최솟값, 25퍼센타일, 중앙값(●), 75퍼센타일, 최댓값. 차트 라벨: type-caption color-text-secondary, 수치 type-body weight 600 color-text-primary.
- 이직 적정 시기 분석 (개인 연차 기반)
- 잠금 콘텐츠: 크레딧 소비로 상세 열람
- 최현직 페르소나 뷰
