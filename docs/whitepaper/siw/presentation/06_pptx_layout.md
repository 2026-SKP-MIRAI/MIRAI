> 버전: 3.0
> 스크립트: `services/siw/generate_presentation.js`
> 총 슬라이드: **27장** / 포맷: 16:9 (10" × 5.625")
> 배경: **전 슬라이드 White (#FFFFFF)**
> 작성 기준: SCQA + StoryBrand + Sparkline / 감정 70% · 데이터 30%

## 디자인 시스템

### 색상 팔레트

| 변수 | Hex | 역할 |
|------|-----|------|
| `white` | `#FFFFFF` | **전체 슬라이드 배경** |
| `offwhite` | `#FAF5FF` | 사용 안 함 (배경은 white로 통일) |
| `purple` | `#7C3AED` | 주 accent — strip, 타이틀 마커, 브랜드 |
| `violet` | `#A855F7` | 보조 accent |
| `lavender` | `#C4B5FD` | 밝은 accent, 구분선 |
| `green` | `#059669` | 완료·성취·기능 accent |
| `body` | `#1E1B4B` | 본문 텍스트 |
| `muted` | `#7E7AA0` | footer, 부제목, 출처 |
| `card` | `#F5F3FF` | 인라인 박스 배경 |
| `cardLine` | `#DDD6FE` | 카드 테두리 |
| `dark` | `#0D0620` | 인라인 accent 박스 (배경 아님) |

### 타이포그래피

> **폰트: Pretendard** — MirAI 메인 서비스 공식 글꼴. 모던 한국어 산세리프.
> 설치: https://github.com/orioncactus/pretendard (무료) / 미설치 시 자동 fallback: 맑은 고딕

| 역할 | 서체 | 크기 | 굵기 | 색상 |
|------|------|------|------|------|
| 빅 넘버 (카드 내부) | Pretendard | 52~80pt | ExtraBold (800) | 감정색 |
| 슬라이드 타이틀 | Pretendard | 26pt | Bold (700) | `body` |
| 전환 슬라이드 메인 | Pretendard | 40~100pt | ExtraBold (800) | `purple`/`muted` |
| 카드 제목 | Pretendard | 13~16pt | SemiBold (600) | accent color |
| 본문 | Pretendard | 11~13pt | Regular (400) | `body` |
| 인용·강조 | Pretendard | 12~13pt | Medium (500) | `purple`/`muted` |
| 캡션·출처 | Pretendard | 9~11pt | Regular (400) | `muted` |

> pptxgenjs에서 굵기는 `bold: true` (700 이상) / `bold: false` (400~600)으로 구분.
> ExtraBold 느낌은 `fontSize`를 키우거나 Pretendard ExtraBold 서브셋 폰트로 적용.

### 반복 시각 모티프

1. **6px 좌측 컬러 strip** — 모든 카드 공통
2. **`titleBar()` 패턴** — 타이틀 좌측 6px purple strip + 26pt Pretendard Bold
3. **사진 플레이스홀더** — `#F0EDFF` 배경 + `lavender` dashed 테두리 (S10, S11)
4. **하단 요약 박스** — `card` 배경 + `cardLine` 테두리 슬라이드 전체 너비 한 줄

## seung SA — #291 유저 행동 이벤트 수집 인프라

│                                                                 │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐  │
│  │ Next.js  │ → │  S3 Raw  │ → │ Airflow  │ → │ S3 집계  │  │
│  │ API      │   │ 이벤트   │   │   DAG    │   │ 결과+API │  │
│  │ routes   │   │ YYYY/MM/ │   │ 일배치   │   │ /events  │  │
│  └──────────┘   └──────────┘   └──────────┘   └──────────┘  │
│  purple      → violet       → green         → lavender        │
│                                                                 │
│  fire-and-forget              collect_events                    │
│  session_started              → aggregate_funnel               │
│  answer_submitted             → load_to_s3                     │
│  report_generated             → alert_on_high_dropout          │
│  report_viewed                  (이탈률 20% 미만 시 경고)       │
│                                                                 │
│  ┌── card ─── 설계 핵심 ──────────────────────────────────┐    │
│  │  이벤트 로깅 실패 → 서비스 응답에 영향 없음 (불변식)   │    │

│  │  퍼널: session_started → answer_submitted              │    │
│  │         → report_generated → report_viewed            │    │
│  └────────────────────────────────────────────────────────┘    │

└─────────────────────────────────────────────────────────────────┘
