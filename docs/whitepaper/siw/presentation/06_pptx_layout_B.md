## B버전 디자인 시스템

### A vs B 핵심 차이

| 요소 | A버전 | B버전 |
|------|-------|-------|
| 카드 마커 | 좌측 6px 컬러 strip | 상단 컬러 accent bar (4px) + 숫자 배지 |
| 타이틀 패턴 | 좌측 strip + 텍스트 | 상단 소형 레이블 → 대형 타이틀 (2-tier) |
| 섹션 전환 | 좌측 purple 패널 | **풀타입 센터 타이포** (Break Section 스타일) |
| 카드 테두리 | `cardLine` 실선 | 없음 + 미세 그림자 (`boxShadow`) |
| 슬라이드 번호 | 우하 텍스트 | 하단 중앙 `•` 도트 페이지네이션 |
| 데이터 강조 | 빅넘버 + 설명 일체형 | 빅넘버 초대형 → 레이블 별도 하단 정렬 |

### 색상 팔레트 (A버전과 동일)

| 변수 | Hex | 역할 |
|------|-----|------|
| `white` | `#FFFFFF` | 전체 슬라이드 배경 |
| `purple` | `#7C3AED` | 주 accent |
| `violet` | `#A855F7` | 보조 accent |
| `lavender` | `#C4B5FD` | 밝은 accent |
| `green` | `#059669` | 완료·성취 |
| `body` | `#1E1B4B` | 본문 |
| `muted` | `#7E7AA0` | 서브텍스트 |
| `card` | `#F5F3FF` | 카드 배경 |
| `cardLine` | `#DDD6FE` | 구분선 |
| `dark` | `#0D0620` | 강조 인라인 박스 |

### B버전 타이포그래피

| 역할 | 서체 | 크기 | 굵기 | 색상 |
|------|------|------|------|------|
| 섹션 브레이크 대형 | Pretendard | 64~80pt | ExtraBold | `purple` / `body` |
| 빅 넘버 초대형 | Pretendard | 72~100pt | ExtraBold | accent |
| 슬라이드 레이블 (소문자) | Pretendard | 9pt | Regular | `muted` (대문자 추적체) |
| 슬라이드 타이틀 | Pretendard | 22~26pt | Bold | `body` |
| 숫자 배지 | Pretendard | 11pt | Bold | `white` on accent circle |
| 카드 제목 | Pretendard | 13~15pt | SemiBold | accent |
| 본문 | Pretendard | 11pt | Regular | `body` |
| 캡션·출처 | Pretendard | 9pt | Regular | `muted` |

### B버전 반복 컴포넌트

1. **`numBadge(n, color)`** — 지름 0.28" 원, accent 색상 배경 + white 숫자 (중앙 정렬)
2. **`accentBar(color)`** — 카드 최상단 4px 컬러 수평 바 (strip 대체)
3. **`sectionBreak(headline, sub)`** — 중앙 정렬 대형 타이포 + 하단 작은 서브 (S05, S26 스타일)
4. **`twoTierTitle(label, title)`** — 9pt UPPERCASE muted 레이블 → 22pt bold 타이틀
5. **`dotPagination(current, total)`** — 하단 중앙 도트 시리즈 (`•` active / `·` inactive)
6. **`shadowCard(x, y, w, h, accentColor)`** — `card` 배경 + 상단 accentBar + 미세 그림자
